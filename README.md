# BLisp

BLisp is an experimental Lisp/brace-and-infix hybrid language implemented in Bash, with both an interpreter and a source-to-Bash compiler.

This repository is being actively developed. The language combines first-class Lisp forms and code-as-data with prototype-oriented objects, closures, conventional/infix syntax, binary data, OS/process/network primitives, and a growing userland standard library.

The implementation is intentionally unusual: the runtime, parser, interpreter, and compiler are Bash.
